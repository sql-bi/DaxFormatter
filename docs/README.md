# Documentation

Each fact has one home; other documents link to it. This folder is for maintainers and contributors; the user documentation is on [SQLBI Docs](https://docs.sqlbi.com/dax-formatter/).

| Where | What lives there |
|---|---|
| [`design/`](design/README.md) | How the system works today |
| [`decisions/`](decisions/README.md) | Why: architectural decision records |
| [`backlog.md`](backlog.md) | What comes next: next work, open decisions, known debt |
| `plans/` | Large work in progress, one file per piece of work; open plans are linked from `backlog.md` |
| [`guides/`](guides/) | How to: release |
