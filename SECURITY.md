# Security policy

## Supported versions

Only the latest release of each package published from this repository is supported: security fixes go into its next release.

## Reporting a vulnerability

Don't report a vulnerability in a public issue, pull request or comment.

Report it privately through GitHub: open [Report a vulnerability](https://github.com/sql-bi/DaxFormatter/security/advisories/new), also found in the repository's Security tab. Only you and the maintainers see the report. Include:

- the package and its version;
- what the vulnerability is and what an attacker could do with it;
- the steps or code that reproduce it.

The maintainers follow up in the advisory, where the fix and its disclosure are discussed with you.

The DAX Formatter service and its remote MCP server are maintained by SQLBI outside this repository; report their vulnerabilities through the same form.
