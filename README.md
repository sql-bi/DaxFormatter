# DAX Formatter

DAX Formatter is a service, available at https://www.daxformatter.com, that formats DAX expressions. This repository holds the packages that call it.

## Packages

- [.NET client library](dotnet/README.md), published on NuGet as `Dax.Formatter`.
- [MCP server](typescript/packages/daxformatter-mcp/README.md), published on npm as `@sqlbi/daxformatter-mcp`: formats DAX from AI clients that support the Model Context Protocol.

## Documentation

The user documentation is on [SQLBI Docs](https://docs.sqlbi.com/dax-formatter/).
